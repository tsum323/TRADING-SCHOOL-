# TRADING SCHOOL

Интерактивный русскоязычный курс для начинающих трейдеров. Первый учебный блок: «Основы трейдинга».

## Что внутри
- 7 последовательных уроков: основы трейдинга, механика биржи, движение цены, P&L и комиссии, участники рынка, виды торговли, принятие решений.
- Практический вопрос с объяснением после каждого урока.
- Последовательное открытие уроков и сохранение прогресса в localStorage.
- Финальное сообщение после прохождения блока.
- Адаптивный тёмный интерфейс для смартфона, планшета и компьютера.

## Запуск
Открой `index.html` в браузере или опубликуй репозиторий через GitHub Pages (Settings → Pages → Deploy from a branch → main / root после слияния изменений).

## Важно
Материал носит образовательный характер и не является финансовой рекомендацией. Примеры цен и комиссий условные. Реальные биржевые данные, API, кошельки и торговые операции не используются.

## Разработка
Основная версия курса находится в ветке `feature/trading-school-learning-block` до проверки и слияния.
