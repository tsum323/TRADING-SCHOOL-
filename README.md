# TRADING SCHOOL

Интерактивный русскоязычный курс для начинающих. Первый учебный блок — «Основы трейдинга».

## Содержание блока

1. Что такое трейдинг
2. Как работает биржа
3. Почему цена движется
4. Как трейдер получает прибыль
5. Кто участвует в рынке
6. Спот, маржа и фьючерсы
7. Как трейдер принимает решения

Каждый урок содержит объяснение простыми словами, примеры, аналогию и проверочный вопрос. После семи уроков доступен итоговый тест из семи ситуационных вопросов. Для завершения блока нужно ответить правильно минимум на шесть вопросов.

## Возможности

- Последовательное открытие уроков.
- Объяснение правильных и неправильных ответов.
- Сохранение прогресса в браузере через `localStorage`.
- Отдельная итоговая проверка знаний с указанием тем для повторения.
- Адаптивный интерфейс для смартфонов, планшетов и компьютеров.

## Запуск локально

Открой `index.html` в современном браузере. Для публикации через GitHub Pages:

1. Открой Settings → Pages.
2. В разделе Build and deployment выбери Deploy from a branch.
3. Выбери ветку `main` и папку `/ (root)`.
4. Сохрани настройки и дождись публикации.

## Границы продукта

Это образовательный тренажёр, а не торговый терминал и не финансовая рекомендация. Цены и комиссии в примерах условные. Реальные биржевые данные, Binance API, кошельки, реальные счета и торговые операции не подключены. Маржинальная и фьючерсная торговля рассматриваются только теоретически; учебный фокус — спотовая торговля.

## Проверки

Основной JavaScript проверен на синтаксические ошибки. Перед публичным использованием дополнительно проверь интерфейс в мобильном и настольном браузерах, последовательное открытие уроков, повторное прохождение итогового теста и сохранение прогресса после перезагрузки страницы.
