# TRADING SCHOOL

Интерактивный русскоязычный курс для начинающих. Первый учебный блок — «Основы трейдинга».

## Содержание

1. Что такое трейдинг — роль трейдера, отличие от инвестирования, качество решений.
2. Как работает биржа — торговые пары, стакан, Market/Limit, matching, maker/taker, проскальзывание и частичное исполнение.
3. Почему движется цена — спрос и предложение, ликвидность, объём, волатильность.
4. Как трейдер получает прибыль — P&L, комиссии, win rate, математическое ожидание и безубыточность.
5. Участники рынка — розничные трейдеры, инвесторы, маркет-мейкеры, крупные участники и биржи.
6. Спот, маржа и фьючерсы — устройство инструментов и их риски; практический фокус курса только на споте.
7. Как трейдер принимает решения — торговая идея, вероятность, риск, расчёт размера позиции и торговый журнал.

## Обучающий подход

Уроки объясняют механику рынка через практические сценарии, числовые разборы и типичные ошибки новичков. Материал помогает рассуждать о сделках, а не заучивать определения. После каждого урока есть проверка понимания с объяснением ответа. После семи уроков — итоговый ситуационный тест из семи вопросов; порог завершения — 6 правильных ответов.

## Возможности

- Последовательное открытие уроков.
- Сохранение прогресса в браузере через `localStorage`.
- Подробные числовые примеры, включая среднюю цену исполнения, комиссии, ожидаемое значение и размер позиции.
- Итоговый тест с указанием тем для повторения.
- Адаптивный интерфейс для смартфонов, планшетов и компьютеров.
- Мобильное боковое меню закрывается кнопкой, нажатием на затемнённую область, клавишей Escape или выбором урока.

## Локальный запуск

Открой `index.html` в современном браузере.

## Публикация через GitHub Pages

1. Открой Settings → Pages.
2. В разделе Build and deployment выбери Deploy from a branch.
3. Выбери ветку `main` и папку `/ (root)`.
4. Сохрани настройки и дождись публикации.

## Границы продукта

Это образовательный тренажёр, а не торговый терминал и не финансовая рекомендация. Цены и комиссии в примерах условные. Реальные биржевые данные, Binance API, кошельки, реальные счета и торговые операции не подключены. Маржинальная и фьючерсная торговля рассматриваются теоретически; учебный фокус — спотовая торговля. Примеры управления риском предназначены для обучения и не являются рекомендацией по размеру позиции или допустимому риску.

## Проверки

Проверены синтаксис JavaScript, наличие семи уроков и семи итоговых вопросов, необходимые DOM-элементы, уникальность HTML ID, а также обработчики закрытия бокового меню. Полное сквозное тестирование в реальном браузере и на разных устройствах ещё требуется.
